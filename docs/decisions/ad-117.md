# AD-117 — `turn_base_sha` resolves sha from the event's own working directory, not the project root

- **status**: active

## Decision

1. **`prompt-submit.ts` resolves `turn_base_sha` via `shaScopeRoot(event)`**
   ([/decisions/ad-114.md](/decisions/ad-114.md)), not `event.projectDir`. Same helper, same
   fallback (`event.cwd ?? event.projectDir`), no new mechanism.
2. **Everywhere `turn_base_sha` is stored and read is unchanged.** The handoff file still lives at
   `event.projectDir` — only the sha *value* recorded in it changes.

## Why

**This is the exact gap AD-116 flagged and deferred, now confirmed live.** AD-116's "Not decided
here" named it explicitly: *"`turn_base_sha`'s own worktree-scoping... plausibly also wrong inside a
worktree, [but this] reuses `stop.ts`'s exact mechanism rather than inventing a second, possibly
divergent answer to the same open question."* A worktree session hit it directly: a file's original
docstrings, deleted earlier in the turn and then restored via `git checkout origin/main -- <path>`
(byte-identical to what was on `main` before the turn started), still failed the comment gate with
the same violation count — because `turn_base_sha` had recorded the *main checkout's* HEAD, not the
worktree's, so the diff base shared no history with the file at all and every line in it read as
newly added.

**Every gate that scopes by `turn_base_sha` was equally exposed**, not only comments: duplication
and supply-chain both diff `listChangedRepoFiles(root, turnBase)` the same way. Fixing the shared
producer (`prompt-submit.ts`) fixes all three consumers at once, the same shape as AD-116's own
`computeTurnScope` sharing across the ship-gate and the comment check.

## Trade-offs

None beyond AD-114's own: `event.cwd` is absent on hosts/event kinds that do not report it (Cursor's
`beforeSubmitPrompt` has no documented per-event `cwd`, per AD-116's research), so `turn_base_sha`
for those falls back to `event.projectDir` — identical to the pre-AD-117 behavior, no regression.

## Not decided here

- **Retroactively correcting a handoff file already holding a wrong `turn_base_sha`** from before
  this fix. The next `prompt.submit` in that session overwrites it; nothing to migrate.
